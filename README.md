### 🤖 Como uso IA
 
IA faz parte do meu dia a dia de engenharia, mas as decisões continuam sendo minhas: eu reviso, testo e me responsabilizo por tudo o que vai para produção.
 
- **No desenvolvimento:** uso agentes de código (Claude Code) para investigar bugs, refatorar código legado, escrever testes e revisar pull requests
- **Em arquitetura:** discuto trade-offs, modelagem de dados e desenho de sistemas antes de implementar, usando a IA como par de revisão
- **Em automações:** construo pipelines que usam APIs de LLM para processar conteúdo e eliminar tarefas repetitivas, como um fluxo automatizado de cortes de vídeo
- **No aprendizado:** estudo system design, algoritmos e arquitetura com apoio de IA, sempre conferindo nas fontes
